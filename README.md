# Phage Quest: The Lambda Switch

An interactive browser game that teaches how lambda phage chooses between the lytic and lysogenic cycles.

- 3 chapters, 15 questions
- Labelled phage diagrams, sorting and ordering puzzles
- A live Cro vs CI switch simulation
- Runs in any modern browser, no install needed

## Play
Open the GitHub Pages link of this repository.

## Run locally
Download `index.html` and open it in a browser.

## Topics covered
Phage structure, infection, lytic cycle, lysogenic cycle, prophage, integrase, Cro, CI repressor, CII, RecA and induction.

Built for BTY323 Microbiology (Unit II).
